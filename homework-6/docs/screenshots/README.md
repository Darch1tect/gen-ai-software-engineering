# Screenshots checklist

Every piece of functionality below has been verified end-to-end while building this project (see
commit messages and `HOWTORUN.md`), but the 5 screenshots `TASKS.md` requires all capture an
**interactive Claude Code terminal session** — something that has to be captured from your own
screen, not generated by an agent running headless. Run each step below yourself and save the
result here with the exact filename.

| File | Capture this |
|---|---|
| `pipeline-run.png` | Full terminal output of `.venv/bin/python integrator.py` (see [HOWTORUN.md](../../HOWTORUN.md#2-run-the-pipeline)) |
| `test-coverage.png` | Output of `.venv/bin/python -m pytest --cov=agents --cov=integrator --cov-report=term-missing` — should show ~98% ([HOWTORUN.md](../../HOWTORUN.md#3-run-the-tests-and-check-coverage)) |
| `skill-run-pipeline.png` | The `/run-pipeline` slash command executing in a Claude Code session ([HOWTORUN.md](../../HOWTORUN.md#5-use-the-claude-code-skills)) |
| `hook-trigger.png` | The coverage-gate hook firing — either blocking a real `git push` with coverage artificially dropped below 80%, or the synthetic stdin payload from [HOWTORUN.md](../../HOWTORUN.md#4-try-the-coverage-gate-hook) showing exit code 2 |
| `mcp-interaction.png` | A context7 query result **and** a custom MCP tool call (e.g. `get_transaction_status`) in the same screenshot or two stitched together ([HOWTORUN.md](../../HOWTORUN.md#6-query-the-pipeline-via-mcp)) |

Once captured, embed or link these same 5 images in the pull request description, per
`TASKS.md`'s submission checklist.
